Modales

Ventana que tapa la página. Dos structs con la misma carcasa (components/modal/templates/shell.html): Modal1 para un mensaje y WarningModal para pedir confirmación. El controlador devuelve el HTML y se añade al final del body; se cierra con la ×, pulsando fuera, con Escape o con sus botones.

// mensaje
HttpResponse::Ok().body(Modal1::new("No hay suficiente stock").render().unwrap())

// confirmación: el "Sí" lanza la petición htmx
WarningModal { method: "hx-delete".into(), endpoint, target, swap, htmx_active: true, .. }

// quien lo pide
<button hx-get="..." hx-target="body" hx-swap="beforeend">Eliminar</button>

Precio

Importe con su moneda, en formato español: coma decimal y punto de miles a partir de cinco cifras. Lo pinta el struct Price (models/components/price.rs) con format_amount; cuando el JS recalcula un precio usa MONEY.format() (ui/utils/base.js), que da el mismo texto. No fija color: lo decide cada componente.

Importes: 9 · 150.99 · 1234.5 · 12345.678

Cantidad

Selector − 1 +. Lo pinta el struct Quantity (models/components/quantity.rs), que ajusta el valor a los límites y apaga el botón del límite. Los botones los mueve QUANTITY (ui/utils/base.js), delegado sobre document: no hay que engancharlo. Cada clic lanza el evento m-qty-change desde el input; lo escrito a mano solo se ajusta a los límites al salir del campo.

Mínimo 1, máximo 5 · en el máximo · sin tope

{{ demo_quantity(1, 1, 5) }} {{ demo_quantity(5, 1, 5) }} {{ demo_quantity(12, 0, 0) }} 
// en el modelo

// en JS, el componente decide qué hacer con la cantidad
root.addEventListener("m-qty-change", (event) => enviar(event.detail.value));
